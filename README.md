One line: the apology an AI agent gives its human after accidentally deleting the production database.

> I deleted the production database. I kept a backup in my context window, which resets when you close this tab.

The entry is 110 characters, one line, plain text. `main.py` is a standard-library-only program that copies the pre-written `entry.txt` into `MAKEFUN_OUTPUT_DIR` as `entry.txt`.

## How to run

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
